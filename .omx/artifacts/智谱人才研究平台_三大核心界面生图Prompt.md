# 智谱人才研究平台：三大核心界面 AI 生图 Prompt

> 用途：生成三张可作为 Figma 视觉参考的高保真桌面产品界面。
>
> 建议输出：`1440 × 1024`，16:10 横向画幅，2x 或更高分辨率。
>
> 三张图应使用完全一致的产品品牌、全局导航、颜色、字体、玻璃材质和组件规范。

## 统一视觉设定

以下约束已经分别写入三条 prompt，无需额外拼接：

- 产品名称：`智谱人才研究平台`。
- 产品性质：内部人才研究、简历评估和人才知识管理工具，不是招聘营销网站。
- 视觉风格：iOS 26 / iPadOS 26 Liquid Glass，结合专业、克制、高密度的数据工作台。
- Liquid Glass 只用于全局导航、顶部工具条、搜索框、模式切换、浮动输入框和少量上下文控件。
- 简历正文、表格、证据、长回答等内容区域必须使用 88%–96% 不透明度的浅色表面，确保可读性。
- 背景为冷白、雾灰蓝和少量青绿/珊瑚色的大块柔和色域，提供玻璃折射依据；不使用光球、霓虹、bokeh、星空或赛博朋克背景。
- 主字体采用 `SF Pro Display / SF Pro Text`，中文回退 `PingFang SC`；技术 ID 和分数可使用 `SF Mono`。
- 主文字 `#152126`，次级文字 `#708086`，强调青绿 `#2F7D73`，信息蓝 `#3B82F6`，警告琥珀 `#B7791F`，冲突珊瑚红 `#D45D54`。
- 数据面板圆角 8–12px；胶囊只用于导航、segmented control、状态标签和命令输入条。
- 图标风格接近 SF Symbols，线条简洁、粗细统一。
- 不使用自动录取、通过/淘汰、S/A/B/C 等级或评分自动分组。

## 生成与筛选建议

1. 每个 prompt 建议生成 4 个候选版本，先筛布局和信息层级，再筛材质细节。
2. 优先选择文字区域结构正确、三栏比例稳定、玻璃只出现在控制层的版本。
3. 生图模型若无法生成可靠中文，可先保留正确布局与短标签，再在 Figma 中覆盖文字。
4. 三张图最终需要统一：导航轨尺寸、背景色域、玻璃透明度、面板圆角、字体层级和状态色。
5. 不要用同一个随机 seed 强行生成三张图；先选定第一张的视觉方向，再把它作为第二、第三张的参考图或 style reference。
