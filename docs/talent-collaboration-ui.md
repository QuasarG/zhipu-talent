# 人才评估协作界面

## 范围

仅人才评估的运行与报告过程入口使用新组件。奖学金以及共享旧协作组件保持本轮开始时的状态。

## 信息与交互

- 主画面呈现系统调度、能力分析、任务评估、总审；实例出现由真实事件决定。
- 角色下面展示任务与状态；最新实际交接用有向线及摘要呈现。线不是推测的数据依赖图。
- 点击角色或交接展开侧面详情；工作全文、工具依据折叠。不显示内部 ID、协议或事件计数。
- 历史默认展示完成状态，可回看协作、暂停、定位并回到结果。暂停冻结角色，结束读取尾部所有事件。
- 窄屏按角色顺序纵向排列，详细内容可独立滚动；键盘选择、Escape 关闭、焦点返回与减少动效可用。

## 实现与边界

沿用现有语义主题变量与字体，独立 `tc-` 样式避免改动奖学金。保留原 Grok 引擎与声明，新增源头移动反馈。页面读事件，不写数据；分页游标取已读取页尾，解析配对后固定运行 ID，卸载忽略旧请求。

准入当前并无主席。后端只提供部分事件，不能从缺失的派工内容生成真实对话。历史报告的配对解析仍由现有 API 选择最近运行，报告与特定运行的精确关联需后续后端工作。本轮不改变该接口。

## 本地预览

`node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5182`（frontend 目录），访问 `/__preview/talent-collaboration`。只在开发模式启用；明确标注合成数据，不调用真实评估，不读写人才库。生产构建不包含该预览入口。

浏览器已检查并行、详情、完成态和回放，390px 窄屏无页面横向溢出。尚未完成真实后端端到端评估、密集消息压力验证或用户视觉验收。当前是供用户检查的交互实现，不代表完整二维协作编排已验收。
