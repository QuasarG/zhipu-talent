# 人才研究平台领域语言

本文件定义人才研究平台中容易混淆的核心业务术语。功能规则与实现决策记录在 `docs/backend_use_case_decisions.md`。

## 人物与人才

**人物主档（Person）**：
系统对一个自然人的统一身份记录，可由人物调查或简历流程建立，不代表该人物已经进入人才库。
_Avoid_: 人才、候选人、嘉宾档案

**人才档案（Candidate）**：
已经由明确业务动作纳入人才库的人物记录，与人物主档一一关联。
_Avoid_: Person、搜索结果

**人才来源（Candidate Source）**：
人物成为人才档案的业务来源，可以是简历评估成功或人物调查后人工加入；同一人才可以同时拥有多个来源。
_Avoid_: 人才类型、固定分类

**HR 跟进状态（Engagement Status）**：
HR 对人才当前联系和推进阶段的人工记录，与能力评价、推荐 Track 和论文核验相互独立。
_Avoid_: 评估等级、筛选结论

## 业务流程

**简历评估（Resume Evaluation）**：
基于简历证据评价候选人的能力结构并推荐研究 Track，不自动决定通过、不通过或人才分档。
_Avoid_: 简历初筛、录取决策

**Track 推荐（Track Recommendation）**：
根据简历中体现的能力、项目、论文和技能，推荐一个或多个宽泛研究方向，并保留理由、证据与置信度。
_Avoid_: 录取方向

**入库身份归并（Intake Identity Resolution）**：
在建立或关联人才档案前，结合稳定标识和 AI 语义判断确定输入材料是否属于已有人物。
_Avoid_: 初筛、能力评分、人才分类

**已知人物调查（Known-person Investigation）**：
围绕一个可识别的具体人物，调查其研究范围、关键高引论文和公开舆情；它是人才知识 Agent 的一种意图，不再是独立产品入口。
_Avoid_: 独立人物调查产品、人才发现

**人才发现（Talent Discovery）**：
按研究关键词、机构或论文条件发现一批未知人物的流程，当前明确不在实现范围内。
_Avoid_: 已知人物调查

**人才库（Talent Pool）**：
保存已纳入人才的完整档案、来源和历史信息，支持查询、比较与人工管理，不是自动录取系统。
_Avoid_: 人物库、搜索结果库、自动筛选器

**人才库问答（Talent Pool Q&A）**：
通过自然语言检索、汇总和比较人才库已有信息的交互形式，回答必须能够追溯到具体人才档案和证据。
_Avoid_: 通用聊天、人才发现

**人才知识库（Talent Knowledge Base）**：
人才库的查询与呈现能力总称，同时包含对话问答和结构化浏览两种只读交互形式。
_Avoid_: 单一聊天界面、外部人才搜索引擎

**人才知识 Agent（Talent Knowledge Agent）**：
接收自由自然语言请求，识别人才查询或已知人物调查意图，并编排库内检索和外部工具形成带来源回答的 Agent 工作流。
_Avoid_: 固定人物调查表单、简历评估 Agent

**人才关系图（Talent Relationship Graph）**：
以人才、学校、机构和研究方向等实体及其有证据的关系构成的可视化知识图谱视图。
_Avoid_: 无来源社交关系、仅按姓名推断的关系

## 论文信息

**论文自述状态（Claimed Publication Status）**：
AI 根据简历原文语义提取的论文状态，属于候选人陈述，不等于外部事实已经确认。
_Avoid_: 核验状态

**论文核验状态（Publication Verification Status）**：
论文标题、发表信息和作者顺序与外部来源对齐后的状态，包括已核验、待核查和存在冲突。
_Avoid_: 投递状态、论文真假
