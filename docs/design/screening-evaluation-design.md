# 简历初筛评估体系设计（v1，2026-08-16 定稿）

> 场景（leader 拍板）：**面对新简历，给出建议面试的人选**。产品第一性功能 = 简历初筛。
> 本文档是该场景下评估体系的唯一设计依据；历史讨论见 `docs/reviews/AUDIT.md` §6。

## 0. 设计公理（由场景直接推导）

1. **绝对尺**：简历持续到达，分数必须跨批次可比，阈值才有意义。相对排序只是展示层。
2. **Top 精度优先**：错放进面试 = 浪费面试官时间；错杀 = 埋没人。档位决策质量 > 全池拟合。
3. **解释性是刚需**：每条分数必须能回答"为什么"。证据链保留——但证据决定**解释**，不再决定**天花板**。

## 1. 输出契约（每次评估产出）

| 字段 | 说明 |
|---|---|
| `overall_score` | 0-100，跨批次可比，配 `config_version`（含证据集 hash） |
| `recommendation` | 强烈建议面试 / 建议面试 / 暂缓 / 不建议（阈值见 §6） |
| `direction_profile` | 方向适配 Top-2 + 分数（去向参考，不参与初筛决策） |
| `jd_matches` | 契合 JD Top-N：契合分 + 命中/缺口清单（带 evidence 引用，见 §5.3） |
| `core_strengths` / `potential_risks` | 每条绑定 evidence id，禁空话 |
| `interview_questions` | 针对风险点与贡献边界的追问 |
| `packaging_risk` | 包装嫌疑标记（§4.3），先进 risks，不直接改分 |
| `low_information` | 信息不足标记：提示 HR 走补充材料流程而非直接低分 |

## 2. 证据层：三类别 × 三通道

抽取时每条证据多打一个 `info_class` 字段，类别决定处理通道：

| 类别 | 定义 | 通道 | 待遇 |
|---|---|---|---|
| `title_fact` 成就事实 | 客观可核验、高筛选性：CCF-A 一作/共一、best/outstanding paper、市状元、IOI/ICPC 金、顶级开源核心作者 | **锚定** | 单条即可支撑相关维度高分，**穿透一切计数 gate**，贡献 overall 峰值地板 |
| `action_fact` 具体行为 | 用什么做了什么、实现/验证了什么 | **常规** | 现行 evidence 逻辑（修 gate，见 §3） |
| `vague_claim` 模糊表述 | 只有方向/参与描述 | **推断** | 不封顶。模型结合**全文上下文**（含成就事实的 halo）做典型实质推断，给**固定折扣 ×0.8** 的暂估，产出标注"含推断成分" |

**放大镜原则**：细节只放大实质（好更好、差更差），本身不加分。同一实质，详写 vs 简写的分差从现状的 ~70% 压到固定折扣 ~20%。

**推断防套利**：推断永不能产生峰值（4.5+ 必须有事实类证据）；全文皆模糊且零成就事实 = `low_information`，走 HR 补料流程而非压分。

## 3. 计数 gate 改造清单（拆"写细=高分"的传导链）

| 现状 | 改为 |
|---|---|
| 无证据引用 → 封顶 1.0 | 保留，但只适用于"连推断通道都无可推断"的维度 |
| 无量化数字 → 封顶 2.5（`has_metric` 看文本有没有数字） | 判定改为抽取期 LLM 标注"有无实质可核验结果"（产物/验收/发表/对照），不看字面数字 |
| `has_specific_tool` 算"验证" | **移出**验证三元组；工具名只是信号，不是成果 |
| portfolio floors：6 来源+3 ownership+2 发表 → 六维抬 4.0-4.5 地板 | **删除纯条数触发**；峰值地板只由 `title_fact` 通道产生 |
| 高分需"多来源/多条" | 计数对象从"证据条数"改为"成就单元数"（同 source 证据折叠为一个成就单元） |

## 4. 能力分结构

### 4.1 通用六维（保留权重）
problem_definition 8 / research_rigor 9 / learning_transfer 3 / ownership 8 / evidence_credibility 9 / growth_trajectory 3（满分 40）。

### 4.2 Track 维度
现阶段沿用 JD 池激活 spec（60 分制）；方向图落地后切换（§5）。

### 4.3 包装检测（初筛的一等输出）
包装 = 表达密度高 + 实质密度低（动作/工具堆叠、零闭环）。机制：抽取期对每条 `action_fact` 标"有无闭环"（指标/验证/产物），对简历整体算闭环率；闭环率低且文本密度高 → `packaging_risk`。叠加 academic_report 的核验冲突。**先只进 risks 不改分**，积累标注样本后再校准是否进分。

## 5. 方向画像与 JD 精准联动（终结"一 JD 一 track"）

初筛输出的是两问：**能不能面（能力闸，JD 无关）** 和 **面哪去（去向匹配，JD 相关）**。
两问分开算，分数口径才不会互相污染。

### 5.1 方向图（去向坐标系）

- 从 Moka 全量 JD（162+，定期重爬）聚类 + LLM 命名 + 人批，~10 个方向，版本化冻结。需求侧校准过的坐标系，稳定、慢演化；
- 方向分：证据 × 方向需求对照评分，产出 `direction_profile`（不进 overall）；
- 新方向只在"映射置信度低"时提议新增，人批入库。

### 5.2 JD 侧结构化（联动的前提）

JD 解析输出升级（起草器从"造 track spec"降级为"映射 + 抽标签"）：

```
spec = {
  direction_weights: {方向: 权重},        # 挂到方向图，不铸造新 track
  must_have: [硬门槛标签],                 # 如 "熟悉 diffusion"、"多机多卡训练"
  bonus: [加分项标签],                     # 如 "顶会一作"、"开源核心贡献"
}
```

### 5.3 两层匹配

| 层 | 机制 | 覆盖 | 产出 |
|---|---|---|---|
| L1 规则匹配 | 方向权重 × 方向画像 + 标签对冻结证据 signals 命中 | 全员常开，零 LLM | 契合分 + **命中/缺口清单（带 evidence 引用）** |
| L2 LLM 深析 | 冻结证据 + JD 原文逐对分析 | 按需；书院规模可全量预计算（28×N），规模化后退化为仅初筛通过者 | 候选人×JD 契合报告 |

HR 看到的不是 0.81，是「命中：多机多卡训练 ← e007」「缺口：diffusion 经验」的对账单。

### 5.4 与现行 JD track 评估的取舍（已拍板）

评估链路的 track 部分归还给方向图（稳定、JD 无关）；**JD 特异性全部移到匹配层**。
现行"JD spec 进评估打 60 分"作为过渡保留（已激活的 AI院 spec），不再扩展，匹配层上线后退役——同一契合度绝不在两处算两遍。

## 6. 稳定性、阈值与成本

| 项 | 决策 |
|---|---|
| 证据冻结 | raw_text hash 命中即复用上次证据集（同简历重复评估证据零漂移，且省钱） |
| 评分稳定性 | 锚点 rubric：每维度每档 2-3 个脱敏真实锚点（"3 分长这样、4.5 长这样"） |
| 多轮策略 | **自适应**：距阈值 \|score−threshold\| ≥ 5 → 单轮；< 5 → 3 轮中位数（钱花在决策边界上） |
| 初始阈值 | ≥80 强烈建议，60-79 建议，<60 暂缓（上线后按面试结果回流校准） |
| 方差测量 | consistency 管线：抽取 Jaccard + 评分 std 分开测，golden 简历集回归 |

## 7. 实施阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 | 证据 `info_class` 三分类 + §3 gate 改造 + 成就单元折叠 | 同一实质详/简写两版简历，分差 ≤ 20% |
| P1 | 推断通道（含 halo 传导与固定折扣）+ 证据冻结 | 模糊简历不再吃 1.0 死刑；同简历两次评估证据集一致 |
| P2 | 锚点 rubric + 自适应多轮 | 边界案例 3 轮 std ≤ 0.3 |
| P3 | Moka JD 聚类 → 方向图；JD 解析升级（direction_weights + must_have/bonus 抽标签）；L1 规则匹配层 | 方向图人批入库；契合分 + 命中/缺口清单产出 |
| P4 | L2 LLM 深析（按需）；面试结果回流校准阈值 | 契合报告可 review；有校准报告 |

## 8. 明确不做的

- 不做"一 JD 一评估 track"（规模化自杀，已废弃）；
- 不做信息置信度 rubric（又是一套规范 LLM 的规则，用固定折扣替代）；
- 不做自进化（等数据反馈闭环建立后再议）；
- 幻觉校验维持现状（当代模型长上下文幻觉不是主要矛盾）。
