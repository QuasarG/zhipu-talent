## 目标与边界

让用户直接看懂：谁正在工作、谁向谁交接、传了什么、各 Agent 如何执行任务。

已确认方向：抽象几何 Agent，靠近、转向与交接体现协作；不做写实办公室或具体人物。详情复用已有问答 Agent 的流式消息和工具组件。

- 仅制作独立交互原型，不改生产评估页面、不部署、不写真实业务数据。
- 示例事件、材料、输出和播放时间全部标注为合成演示，不冒充真实运行或模型 token 流。
- 不控制浏览器；构建与静态检查由开发完成，视觉及交互体验由用户验收。
- 参考 grok-icon-study 的状态表达思路，不复制其角色、几何数据、提取素材或代码；该仓库声明仅供学习、禁止商用与再分发。
- 分支：`codex/agent-space-prototype`。原型不合并到 master；确认设计后再制定生产接入任务。

## 7.5 原型使用说明

- 访问地址：`cd frontend && npm run prototype:agents`，打开 `http://127.0.0.1:5178/prototype/agent-space`（仅开发环境注册该入口；追加 `?variant=A|B|C` 直达布局）。
- 操作方法：底部播放条播放/暂停/重播/调速/拖动定位；点击 Agent 固定详情，“已跟随当前 Agent”切回自动跟随；点击交接条或交接记录回看该次交接；左右方向键或右下角胶囊切换 A/B/C 布局；“减少动效”冻结姿态动画。
- 复用组件：`AssistantMessage`（问答消息与工具卡片渲染）、`Icon`、主题与 i18n Provider；状态由 `scenarios.ts` 的 `snapshot()` 按播放时间重建。
- 合成数据：两个场景的全部事件、材料、文字输出均为预编写演示；不调用模型、不读取真实候选人、不产生评分。
- 未接入能力：真实事件流、评估服务、鉴权、部署、生产路由均未接入；接入需另行规划。
- 参考边界：仅借鉴 grok-icon-study 的“状态机驱动姿态 + 低频小幅保持活性 + 状态切换瞬时弹跳”思路；未复制其角色、几何数据、素材或代码。
